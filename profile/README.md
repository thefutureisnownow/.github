## Deliberately leaked

Open source, MIT licensed. Containment has been officially abandoned.

| | |
|---|---|
| [**Coldshift Dash**](https://github.com/thefutureisnownow/coldshift-dash) | Turns an old Android phone into a car dashboard: offline maps and navigation, engine readings, music, a dashcam and convoys, on phones as old as Android 4.4. |
| [**Convoy**](https://github.com/thefutureisnownow/coldshift-dash-convoy) | Cars driving together see each other on a live map and send messages and voice notes, through a relay anyone can run on Cloudflare Workers. |
| [**LocalNet**](https://github.com/thefutureisnownow/godotlocalnet) | Offline local multiplayer for Godot 4. No internet, no router, no WebRTC and no native code. |
